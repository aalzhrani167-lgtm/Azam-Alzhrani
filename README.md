# Z7R Store Web Edition

واجهة ويب أولية لإدارة أرشيفات ZIP وفحص ملفات مودات السيارات وتعديل ملفات النصوص.

## التشغيل محليًا
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`
4. نفّذ `npm start`
5. افتح `http://localhost:3000`

## الوظائف الحالية
- رفع ZIP إلى الخادم (حد التطبيق 1GB).
- فك ضغط ZIP مع فحص مسارات الأرشيف ضد Zip Slip.
- عرض الملفات وأحجامها.
- تحرير ملفات نصية محددة (TXT/INI/CFG/XML/JSON/META/LUA وغيرها) حتى 2MB للملف.
- إنشاء تقرير يكتشف امتدادات YFT وYTD وMETA.
- تنزيل ملفات المشروع مجددًا في ZIP.

## حدود مهمة
- لا يوجد في هذه النسخة محرك تحويل FiveM إلى RPF. مجرد قراءة YFT/YTD أو تجميعها داخل ZIP لا ينتج RPF صالحًا.
- لا يتم تحرير الملفات الثنائية أو تعديل خامات YTD أو نماذج YFT.
- توافق PS4 GoldHEN وGTA V 1.56 غير مضمون ولا يمكن تأكيده دون أداة تحويل مناسبة واختبار على الجهاز.
- دعم رفع 1GB يعتمد أيضًا على إعدادات الاستضافة والوكيل العكسي ومساحة القرص والذاكرة. استخدم HTTPS، ومصادقة، وحدود استخدام، وتنظيفًا دوريًا للملفات قبل نشر الموقع للعامة.
- خط المجاهد غير مضمن. يمكن إضافة ملف الخط المرخّص بصيغة WOFF2 لاحقًا إلى `public/fonts` وربطه في CSS.

## قبل النشر العام
أضف تسجيل دخول وصلاحيات، تخزينًا خاصًا لكل مستخدم، انتهاء صلاحية المشاريع، مكافحة إساءة الاستخدام، ومراقبة المساحة. لا ترفع ملفات ألعاب لا تملك حق استخدامها أو توزيعها.
